# TBS Classes - Next.js Application

A modern, professional, responsive educational website for TBS Classes.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React (Icons)

## Getting Started

Since the Next.js project was generated, but Node.js was not available in this environment to install dependencies, you will need to run the following commands on a system with Node.js installed to get the project running.

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure
- `src/app/`: Next.js App Router pages and layout.
- `src/components/`: Reusable React components (Navbar, Footer, Hero, SubjectCard, etc.).
- `tailwind.config.ts`: Tailwind configuration including custom colors for the TBS Classes brand identity.

## Brand Identity
- **Primary Color:** Warm Yellow / Golden (`#FFB800`)
- **Text Color:** Navy / Charcoal (`#1A202C`)
- **Design:** Modern cards, soft shadows, rounded corners, professional aesthetic.
